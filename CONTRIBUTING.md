# Contributing

Thank you for your interest in iCode.

## Issues

Bug reports and feature requests are welcome. Before opening an issue, please
search the existing ones. For a bug, include:

- your operating system and VS Code version
- the iCode version
- the steps to reproduce the problem
- what you expected and what happened

Do not include API keys, tokens, or private code in an issue.

## Pull requests

iCode is maintained by a single author and does not accept pull requests at
this time. A pull request opened from outside the project will be closed
without review. If you have found a bug or have an idea, please open an issue.
