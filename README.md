<h1 align="center">iCode</h1>

iCode is an open-source coding agent for Visual Studio Code. It reads your
code, proposes edits as diffs for you to review, and runs commands with your
approval, using a language model you choose.

## Status

iCode is in early development and there is nothing to install yet. Work lands
in small pull requests. Installation and usage instructions will be added here
with the first release.

## Planned

- A chat panel inside VS Code
- File edits shown as diffs before they are applied
- Shell commands that run only after approval
- Your choice of model with your own API key: Anthropic, OpenAI, and any
  hosted provider or local server that offers an OpenAI-compatible API
- A desktop app that shares the same engine
